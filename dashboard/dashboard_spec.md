# Tableau build specification

The project provides data and a precise build guide, **not a native Tableau workbook**. No Tableau account is needed for the executed Python charts or HTML readout.

## Page 1 — Experiment decision

Connect `data/dashboard/experiment_results.csv`. One row per metric with counts, rates, treatment-minus-control effect and confidence limits. Add a metric selector; default to `activated_7d`.

KPI cards: control rate, treatment rate, absolute lift in pp, relative lift. Use the primary row only for those cards. Show an effect dot with lower/upper CI and a zero reference line. Add a banner: “SYNTHETIC PORTFOLIO STUDY — not Monzo customer results.”

Show `guardrails.csv` as a separate sheet with effect, simultaneous upper bound, harm margin and pass/fail. Never filter this sheet by acquisition channel: it contains overall results only. Show sample sizes and SRM from `reports/experiment_summary.json` as a caption or typed parameter value, not an invented calculation.

## Page 2 — Customer journey

Use `funnel.csv`: step order on columns, overall conversion on rows, variant on colour. Tooltip: user count, assignment conversion, previous-step conversion. Preserve the assignment denominator.

Use `segments.csv` for descriptive channel/device bars. Dimension, segment and variant define the row grain. Do not join it physically to experiment results or user-level data, which would multiply rows. Label all segment cuts “Exploratory”.

## Page 3 — Follow-up and reliability

Use `retention.csv`: signup week by return week heatmap, variant filter. Aggregate with `SUM(returning_users)/SUM(eligible_users)`, not an unweighted average across unequal cohorts.

Use `daily_activation.csv` for assigned users and activation trend. Use `data/processed/event_quality.csv` plus `reports/quality_summary.json` for quality counts. Duplicate removal is reported separately from quarantined rows.

## Accessibility and interpretation

Use coral for treatment and dark slate for control, with text labels. Display percentages and percentage points explicitly. Do not imply statistically reliable segment differences. No bank logo or claim of affiliation. Explain that observed lift is generated by simulation assumptions.
